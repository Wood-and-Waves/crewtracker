If something surfaces

Two things are true of the demo and worth knowing before you blame the app:

  • Dates move on every reseed. The show you build is Oct 1–5 because you type it, but Lakeshore's overlap is computed from the same anchor — so check the picker before recording rather than trusting these notes.
  • Every email in this company comes to you. That is the point, but it means the inbox fills up during a session. Clear it before take 3 so the right message is the top one.
