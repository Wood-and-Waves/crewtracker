# "CrewTracker" — trademark search, 2026-09-16

Facts found, not advice. Searched USPTO's Trademark Search (tmsearch.uspto.gov)
and the open web. Entity for the work: **Smith Audio, LLC**.

## What is registered: nothing

One USPTO record contains the word at all, and it is dead.

| | |
|---|---|
| Mark | **CREWTRACKER SOFTWARE** |
| Serial | 86175766 |
| Filed | 2014-01-27 |
| Status | **DEAD — ABANDONED**, 2014-12-05 |
| Why | "Abandoned because the applicant failed to respond or filed a late response to an Office action." |
| Registration number | none — it never registered |
| Class | 009 — "Computer application software for mobile phones, namely, software for comprehensive business administration and management" |
| First use claimed | 13 March 2012; in commerce 25 June 2012 |
| Owner | CrewTracker Software, LLC — DeSoto, Kansas |
| Mark type | **Words plus design** (the stylised logo), no standard-character claim |

Nothing is registered in Class 009 or 042 that blocks "CrewTracker".

## What matters more: they are still trading

**crewtracker.com is live, © 2026.** The site reads: *"CREWTRACKER SOFTWARE
provides business operations software solution for service businesses
specializing in snow and ice management and landscaping."* Contact is a
`@paguar.com` address.

So the abandonment is not the end of it. **A trademark does not have to be
registered to exist**: use in commerce creates common-law rights in the area
where the mark is used, and this company has been using the identical name in
software since 2012 by its own claim. An abandoned application means the USPTO
stopped considering it — not that the name was given up.

## The two things that decide it, neither of which is ours to decide

1. **Do the markets overlap?** They sell to snow/ice and landscaping
   contractors. CrewTracker sells to corporate AV production companies. Both are
   "business operations software", which is how their own application described
   the goods — and that phrasing is broad.
2. **How far do their rights reach?** Common-law rights are geographically and
   commercially bounded by actual use. Registration would have been national;
   use is not.

Both are judgement calls for a lawyer, and they are the specific questions to
bring to the consult already on the backlog.

## Things that are true regardless

- **A domain is not a trademark.** We hold `crewtracker.app`; they hold
  `crewtracker.com`. Neither fact settles anything.
- **The code is copyrighted automatically.** Registration is optional and
  separate from any of this.
- **Filing our own application would be the thing that surfaces the conflict** —
  an examiner searches for exactly this, and a live user with earlier first use
  is what an Office action is made of.

## What this does not say

It does not say the name cannot be used, and it does not say it can. It says
nothing is registered, somebody else has used the identical name in software
since 2012, and they are still trading — which is enough to want an answer
before the name goes on marketing, a logo, or a filing.
